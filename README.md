# Магазин - Ionic Angular приложение

Приложение для управления магазином с функциями учета товаров, продаж и аналитики.

## Функциональность

### 🏠 Главная страница
- Навигация по разделам приложения
- Красивый интерфейс с карточками

### 📦 Управление продуктами
- **Добавление нового продукта**: название, цена покупки, цена продажи, количество, дата создания
- **Редактирование продуктов**: изменение всех параметров
- **Удаление продуктов**: с подтверждением
- **Поиск продуктов**: по названию
- **Отображение остатков**: с цветовой индикацией (зеленый - много, желтый - мало, красный - нет)

### 💰 Продажи
- **Создание продажи**: выбор нескольких продуктов для одного клиента
- **Выбор товаров**: из списка доступных продуктов
- **Указание количества**: с проверкой остатков
- **Изменение цены продажи**: не меньше цены покупки
- **Информация о клиенте**: имя клиента и комментарий
- **Корзина**: добавление/удаление товаров
- **Просмотр продаж**: список всех продаж с поиском
- **Детали продажи**: подробная информация о каждой продаже

### 📊 Аналитика
- **Общая статистика**: количество товаров, продаж, выручка, прибыль
- **Остатки товаров**: товары с низким остатком (≤5 штук)
- **Топ продаваемых товаров**: по количеству продаж
- **Последние продажи**: последние 5 продаж
- **Расчет прибыли**: автоматический подсчет прибыли по каждой продаже

## Технические особенности

### Модели данных
- **Product**: товар с полями id, name, buyPrice, sellPrice, quantity, createdAt, addedAt
- **Sale**: продажа с полями id, customerName, comment, items, total, createdAt
- **SaleItem**: элемент продажи с полями productId, name, quantity, sellPrice

### Сервисы
- **ProductService**: CRUD операции для товаров
- **SaleService**: создание и получение продаж
- **ApiService**: базовый HTTP сервис для работы с API

### Валидация
- Проверка обязательных полей
- Валидация цен (цена продажи не меньше цены покупки)
- Проверка остатков товаров
- Обработка ошибок с пользовательскими сообщениями

## Установка и запуск

1. Установите зависимости:
```bash
npm install
```

2. Запустите приложение:
```bash
ionic serve
```

3. Для сборки:
```bash
ionic build
```

## Настройка API

В файле `src/app/services/api.service.ts` измените базовый URL API:

```typescript
base = 'https://your-api-url.com';
```

## Структура проекта

```
src/app/
├── models/           # Модели данных
├── services/         # Сервисы для работы с API
├── home/            # Главная страница
├── products/        # Управление продуктами
├── sales/           # Управление продажами
├── analytics/       # Аналитика
└── sale-modal/      # Модальное окно создания продажи
```

## Использование

1. **Добавление товара**: Нажмите кнопку "+" на странице продуктов, заполните форму
2. **Создание продажи**: Нажмите кнопку "+" на странице продаж, выберите товары и клиента
3. **Просмотр аналитики**: Перейдите на страницу аналитики для просмотра статистики

## Особенности реализации

- Использование Ionic компонентов для нативного вида
- Модальные окна для создания продаж
- Pull-to-refresh для обновления данных
- Поиск и фильтрация
- Цветовая индикация остатков
- Responsive дизайн
- Обработка ошибок и loading состояния
