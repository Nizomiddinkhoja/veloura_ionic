# Изменения в модуле закупок

## Что было реализовано

### 1. ✅ Автокомплит для дилеров и товаров
- **Автокомплит дилеров**: При вводе имени дилера система предлагает существующих из базы
  - Если выбран из списка → отправляется `dealer_id`
  - Если введено вручную → отправляется `dealer_name`
  
- **Автокомплит товаров**: При вводе названия товара система предлагает из базы
  - Если выбран из списка → отправляется `product_id` и автоматически подставляется цена покупки
  - Если введено вручную → отправляется только `product_name`

### 2. ✅ Группировка закупок и возвратов с автоматическим взаиморасчетом
- **Одна транзакция для всех операций**: Теперь в одной закупке можно:
  - Добавить несколько разных товаров
  - Отметить товары как возврат (checkbox "Это возврат товара")
  - Система автоматически вычитает возвраты из закупок
  - **Итоговая сумма = (сумма закупок) - (сумма возвратов)**

- **Упрощенная система без кредитов**: 
  - Убрана система кредитов дилеров
  - Убрана вкладка "Кредиты"
  - Возвраты просто вычитаются из суммы закупки в той же транзакции

## Структура данных

### Purchase (обновлено)
```typescript
{
  dealer_id?: number;        // NEW: ID дилера
  dealer_name: string;
  items: PurchaseItem[];     // NEW: массив товаров
  total_amount: number;      // NEW: общая сумма (закупки - возвраты)
  status: 'completed' | 'pending';
  notes?: string;
  // REMOVED: purchase_type, credit_used
}
```

### PurchaseItem (новая модель)
```typescript
{
  product_id?: number;       // ID товара если выбран
  product_name: string;
  quantity: number;
  buy_price: number;         // цена покупки за единицу
  sell_price: number;        // цена продажи за единицу
  total_cost: number;
  is_return?: boolean;       // флаг возврата
}
```

### Dealer (новая модель)
```typescript
{
  id?: number;
  name: string;
}
```

## API изменения

### Новые endpoints:
- `GET /dealers?search={query}` - поиск дилеров для автокомплита
- `GET /products?search={query}` - поиск товаров для автокомплита

### Удаленные endpoints:
- `GET /dealer-returns` - больше не нужен
- `POST /dealer-returns` - больше не нужен
- `GET /dealer-credits` - больше не нужен
- `GET /dealer-credits/:dealerName` - больше не нужен

### Изменения в существующих:
- `POST /purchases` - теперь принимает массив `items` вместо отдельных полей товара
- Каждый `item` может иметь флаг `is_return: true` для возвратов
- `total_amount` рассчитывается как: сумма(items где !is_return) - сумма(items где is_return)

## UI изменения

### Модальное окно закупки:
1. **Секция "Дилер"**:
   - Поле с автокомплитом

2. **Секция "Добавить товар"**:
   - Поле с автокомплитом для товара
   - Количество и цена
   - Checkbox "Это возврат товара"
   - Кнопка "Добавить товар"

3. **Секция "Товары в закупке"**:
   - Список добавленных товаров
   - Возможность удалить товар
   - Отображение итоговой суммы (с учетом возвратов)

4. **Секция "Статус и заметки"**:
   - Статус
   - Заметки

### Главная страница закупок:
- Убраны все вкладки (была система с вкладками "Закупки", "Возвраты", "Кредиты")
- Теперь простой список всех закупок
- В списке закупок отображаются все товары с пометкой возвратов (badge "Возврат")

## Преимущества новой реализации

1. **Максимальное упрощение**: Убрана сложная система кредитов
2. **Прозрачность**: Сразу видно итоговую сумму с учетом возвратов
3. **Группировка операций**: Все операции с одним дилером в одной транзакции
4. **Автоматизация**: Автокомплит ускоряет ввод данных
5. **Гибкость**: Можно создавать новых дилеров и товары на лету
6. **Простой расчет**: Итого = Закупки - Возвраты
