# Руководство по функционалу закупок и возвратов

## Обзор

Новый модуль **Закупки** добавляет полный функционал для управления закупками товаров у дилеров с возможностью группировки товаров и возвратов в одной транзакции. Возвраты автоматически вычитаются из общей суммы закупки.

## Основные возможности

### 1. Групповая закупка товаров с возвратами

Позволяет регистрировать закупки **нескольких товаров** у одного дилера в одной транзакции с автоматическим взаиморасчетом возвратов.

#### Возможности:
- **Автокомплит дилеров** - начните вводить имя дилера, система предложит существующих
- **Автокомплит товаров** - начните вводить название товара, система предложит из базы с ценами
- **Добавление нескольких товаров** - в одной закупке можно добавить несколько разных товаров
- **Возврат в закупке** - можно отметить товар как возврат (галочка "Это возврат товара")
- **Автоматический расчет** - система автоматически рассчитывает стоимость каждого товара и общую сумму
- **Взаиморасчет** - возвраты вычитаются из закупок автоматически

#### Поля закупки:
- **Дилер** (с автокомплитом - отправляется ID если выбран из списка, иначе название)
- **Список товаров:**
  - Название товара (с автокомплитом - отправляется ID если выбран, иначе название)
  - Количество
  - Цена за единицу
  - Это возврат? (checkbox)
- Общая сумма (рассчитывается автоматически: закупки - возвраты)
- Статус (завершено/ожидание)
- Заметки

## Как использовать

### Создание новой закупки с возвратами

1. Откройте раздел **Закупки** на главной странице
2. Нажмите кнопку **+** (плюс) внизу справа
3. **Выберите дилера:**
   - Начните вводить имя дилера
   - Выберите из предложенных вариантов (отправится ID)
   - Или введите новое имя (отправится название)
4. **Добавьте товары:**
   - Начните вводить название товара
   - Выберите из списка (подставится цена покупки) или введите новое
   - Укажите количество
   - При необходимости измените цену
   - **Если это возврат - поставьте галочку "Это возврат товара"**
   - Нажмите "Добавить товар"
   - Повторите для всех товаров (закупок и возвратов)
5. **Проверьте итоговую сумму:**
   - Система автоматически вычтет возвраты из закупок
   - Итоговая сумма = (сумма закупок) - (сумма возвратов)
6. Добавьте заметки при необходимости
7. Нажмите **Сохранить**

## Бизнес-логика

### Сценарий использования:

**Пример 1: Простая закупка**
1. Создаете закупку у дилера "Поставщик А":
   - Товар 1: 10 шт × 500 сом = 5,000 сом
   - Товар 2: 5 шт × 1,000 сом = 5,000 сом
   - **Итого: 10,000 сом**

**Пример 2: Закупка с возвратом в одной транзакции**
1. Создаете закупку у дилера "Поставщик Б":
   - Товар А: 20 шт × 300 сом = 6,000 сом (закупка)
   - Товар Б: 10 шт × 400 сом = 4,000 сом (закупка)
   - Товар В: 5 шт × 200 сом = 1,000 сом (возврат - ✓ галочка)
   - **Итого: 6,000 + 4,000 - 1,000 = 9,000 сом**
2. Вы платите только 9,000 сом вместо 10,000 сом

**Пример 3: Только возврат**
1. Создаете закупку у дилера "Поставщик В":
   - Товар X: 3 шт × 800 сом = 2,400 сом (возврат - ✓ галочка)
   - **Итого: -2,400 сом**
2. Дилер должен вернуть вам 2,400 сом

## API Endpoints (для бэкенда)

Необходимо реализовать следующие endpoints:

### Закупки
- `GET /purchases` - список всех закупок
- `GET /purchases/:id` - получить закупку по ID
- `POST /purchases` - создать новую закупку (с массивом товаров)
- `PUT /purchases/:id` - обновить закупку
- `DELETE /purchases/:id` - удалить закупку

### Автокомплит
- `GET /dealers?search={query}` - поиск дилеров по имени
- `GET /products?search={query}` - поиск товаров по названию

## Модели данных

### Dealer
```typescript
{
  id?: number;
  name: string;
}
```

### PurchaseItem
```typescript
{
  product_id?: number;      // ID товара если выбран из списка
  product_name: string;     // название товара
  quantity: number;
  buy_price: number;        // цена покупки за единицу
  sell_price: number;       // цена продажи за единицу
  total_cost: number;
  is_return?: boolean;      // это возврат?
}
```

### Purchase
```typescript
{
  id?: number;
  dealer_id?: number;       // ID дилера если выбран из списка
  dealer_name: string;      // имя дилера
  items: PurchaseItem[];    // список товаров в закупке
  total_amount: number;     // общая сумма закупки (закупки - возвраты)
  status: 'completed' | 'pending';
  notes?: string;
  created_at?: string;
  updated_at?: string;
}
```

## Доступ

Функционал доступен только для **администраторов** (isAdmin = true).
Кнопка "Закупки" отображается на главной странице только для пользователей с правами администратора.
